# FishEye

Site web accessible pour une plateforme de photographes, développé avec **HTML, CSS et JavaScript**.

Le projet permet de découvrir différents photographes et leurs travaux à travers une interface interactive et accessible.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- JSON
- Git / GitHub

## ✨ Fonctionnalités

- Affichage dynamique des photographes et de leurs médias
- Navigation vers la page de chaque photographe
- Système de likes
- Modale de contact
- Lightbox pour consulter les médias
- Gestion des événements avec JavaScript
- Interface responsive et accessible

## ♿ Accessibilité

Une attention particulière a été portée à l'accessibilité du site :

- Navigation au clavier
- Utilisation des attributs ARIA lorsque nécessaire
- Structure HTML sémantique
- Gestion du focus
- Compatibilité avec les technologies d'assistance

## 💡 Compétences développées

- Développement d'une application web modulaire
- Manipulation et affichage de données JSON
- Création de composants et fonctions JavaScript réutilisables
- Gestion des événements JavaScript
- Mise en place d'une Lightbox et d'une modale
- Application des bonnes pratiques d'accessibilité
- Écriture d'un code JavaScript maintenable
